# yunohost-mcp

Secure MCP server for YunoHost: Nostr-authenticated, policy-controlled, auditable administration and diagnostics for AI clients (Codex, Claude, OpenCode, ChatGPT-compatible MCP clients).

See [PLAN.md](PLAN.md) for the full design and phased roadmap.

Status: scaffolding only, no implementation yet. v0.1 scope is read-only introspection (server info, diagnosis, apps, services, operations) via NIP-98 signed requests — no destructive writes.
